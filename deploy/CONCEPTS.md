# Экспериментальная витрина

Адрес: https://zazemli.com/rubinovoe-more/

Автономная статика с 10 концептами, переключением страниц, AS IS / TO BE, фотографиями и мобильным окном комплектации. Это демонстрация: кнопка покупки показывает переход на маркетплейс, фактический магазин ещё не выбран. Новых форм отправки данных и аналитики нет.

## Обновление

Из корня репозитория:

```bash
scripts/deploy-concepts.sh .superpowers/brainstorm/20987-1789208257/content
```

Перед публикацией проверить изменения в локальном прототипе. `scripts/package-concepts.py` переносит ссылки `/files/` в `/rubinovoe-more/files/`, добавляет meta noindex и собирает только HTML, клиентские ассеты и два публичных JSON. Локальный сервер, его токен, тестовые отчёты, ZIP/DNG и содержимое БЗ не публикуются. Клиентский исходник макетов и нужные браузеру ассеты сохранены в Git в `.superpowers/brainstorm/20987-1789208257/content/`. Служебные файлы сессии и исходные RAW исключены через `.gitignore`; новые клиентские ассеты добавляйте адресно через `git add -f`.

Деплой создаёт новый каталог `/var/www/zazemli-experiments/releases/<UTC-время>/`, загружает сборку и атомарно переключает симлинк `/var/www/zazemli-experiments/rubinovoe-more`. Предыдущие релизы остаются для отката. Основной `/var/www/zazemli` не затрагивается, обычный `scripts/deploy.sh --delete` не удаляет эксперименты.

Конфиг маршрута хранится в `deploy/nginx/zazemli.conf`. Префикс `^~` исключает перехват пути общим правилом удаления завершающего слэша. В экспериментальном location включены общие заголовки безопасности, HSTS, X-Robots-Tag noindex/nofollow/noarchive и обязательная перепроверка кеша. Путь не добавляется в sitemap и навигацию основного сайта. Noindex не является паролем: площадка доступна любому, у кого есть ссылка.

## Прямые ссылки

- Все концепты: `/rubinovoe-more/`
- Второй концепт, главная: `/rubinovoe-more/#concept=2&page=home`
- Он же в мобильном макете: `/rubinovoe-more/#concept=2&page=home&view=mobile`
- Карточка товара: `/rubinovoe-more/#concept=2&page=product`

## Проверка после публикации

Открыть главную площадки и один концепт. Проверить переключение страниц, мобильные метки и покупку. В Network не должно быть 404 и запросов на localhost или корневой `/files/`. Проверить основной сайт `/`, `/lab`, `/guide` и их прежние редиректы. В HTML площадки и заголовках ответа должен присутствовать noindex.

## Откат

Для возврата к прошлому релизу на сервере создать временную ссылку на его каталог в `releases/` и атомарно заменить `rubinovoe-more` через `mv -Tf`. Для полного отключения первого релиза восстановить сохранённый перед публикацией конфиг nginx, выполнить `nginx -t`, затем reload. Файлы основного сайта не требуют восстановления.

Первый проверенный релиз: `20260913T195227Z`. Исходный конфиг сервера сохранён в `/etc/nginx/sites-available/zazemli.before-concepts-20260913T195325Z`.
