# Харденинг VPS zazemli.com — план по итогам дипресерча

Дата: 2026-07-16. Метод: 75 агентов на Opus (5 поисковых углов → 40 источников → прочитано топ-15 →
80 сырых мер → 18 после слияния дублей → верификация каждой тремя линзами: корректность,
применимость к этому серверу, актуальность-2026). Все 18 мер подтверждены; команды ниже —
уже с поправками верификаторов.

Контекст: Ubuntu 24.04, nginx + статика `/var/www/zazemli`, вход root по ключу (`ssh zazemli`),
деплой `scripts/deploy.sh` (rsync). Уже сделано и сюда не входит: ufw 22/80/443, fail2ban,
unattended-upgrades, LE + HSTS, базовые security-заголовки, server_tokens off.
