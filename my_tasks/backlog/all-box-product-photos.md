# Фотографии всех семи боксов «Заземли»

Статус: открыто. Добавлено 13.09.2026 по просьбе владельца.

## Проблема

Фото собранных боксов есть только для «Заземли антуриум» и «Заземли эпипремнум». Для остальных пяти растений имеются фотографии грунта и дневника, но нет отдельного кадра всего бокса.

В экспериментальной витрине `/rubinovoe-more/` галерея этих пяти товаров начинает показ с их собственной раскладки грунта. Это временная замена, задача фотографий не закрыта. В первом экране и интерактивной комплектации для них пока используется общая фотография антуриума — её тоже нужно заменить.

- [ ] Заземли антуриум — проверить имеющуюся съёмку; дополнить кадром с соответствующим растением.
- [ ] Заземли аглаонему — получить фото собранного бокса.
- [ ] Заземли спатифиллум — получить фото собранного бокса.

- [ ] Заземли эпипремнум — проверить имеющуюся съёмку и полноту комплектации.

## Требования к съёмке и размещению

- Для каждого товара: весь бокс рядом с соответствующим живым растением и раскрытая комплектация. Название на дневнике и маркировка должны соответствовать выбранному товару.
- В кадре раскрытого бокса показать грунт, дренаж, набор принадлежностей и дневник. Корневин, угольная пудра и палочки должны быть различимы; листовку с гайдом не возвращать в продаваемую комплектацию сайта без отдельного решения владельца.
- Согласовать общий свет и фон с текущей светлой палитрой bone; проверить кадрирование для компьютера и телефона.
- Сохранить оригиналы в `storage/photos/`, подготовить версии для сайта и обновить карту использования фотографий.
- Привязать фотографии ко всем семи SKU на главной, в коллекции, галерее товара и интерактивной комплектации. Везде использовать название «Заземли + растение».
- Для каждого нового кадра заново выставить точки: 01 — принадлежности, 02 — дренаж, 03 — грунт, 04 — дневник; отдельный плюс — Корневин.
- Сначала проверить в `/rubinovoe-more/`; перенести фотографии в основной сайт при реализации выбранного редизайна.

## Приёмка

- [ ] Все семь товаров имеют собственный кадр собранного бокса с соответствующим растением.
- [ ] При переключении товара меняются его бокс, дневник и грунт; чужих названий на фотографиях нет.
- [ ] Фотография антуриума больше не подставляется для других растений ни в галерее, ни в первом экране, ни в комплектации.
- [ ] Точки попадают на правильные предметы, мобильное окно показывает соответствующие описания.
- [ ] Проверены все семь товаров на компьютере и телефоне; отсутствуют обрезанные названия и битые изображения.
