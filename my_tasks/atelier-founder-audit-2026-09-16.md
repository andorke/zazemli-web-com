# «Ателье пересадки»: концепт + быстрая покупка

Четвёртый режим экспериментальной витрины. Один цельный вариант, рядом с AS IS, десятью концептами и десятью версиями быстрой покупки. Основной сайт не меняется.

Приоритет: свежие указания пользователя → свежие решения Насти → канон Markdown → прототипы. Расхождения не сводились механическим объединением:

- Июньский brief требует Spectral/Unbounded/Caveat, но typography v3.0 и PATCH-1 заменяют их на **Mulish + Commissioner**. Caveat остаётся в печати.
- PATCH-1 разрешает лёгкие заголовки из согласованных прототипов, хотя таблица typography указывает 600 для h1/h2. В макете — Mulish 300/400, настоящий курсив, отрицательный трекинг; UI/тело — Commissioner.
- PATCH-1.1 требует SKU-акцент на карточке вместо moss. Дудл, заголовок, выбор размера и кнопка меняются вместе с растением. Для замиокулькаса buttercup остаётся декором/заливкой, текст тёмный по правилу контраста color-system.
- В media-system расходятся старые примеры дудлов на главной и позднее ограничение товарной страницей. По текущей просьбе пользователя нейтральные маргиналии видны на главной; цветные — только у соответствующего товара.
- Сентябрьская обратная связь пользователя сохраняет крупный бокс первым экраном, открытый состав вторым, коллекцию на главной, интерактивные раскладки, дневник и фото рук. Листовка не возвращена в состав отдельным пунктом.

## Что применено

| Часть | Реализация |
|---|---|
| Базовые цвета | Bone `#F6F4F0`, Charcoal `#1C1C1C`, Chalk `#EDEBE6`; Moss `#4A7C59`, мелкий зелёный текст `#406C4F` |
| Типографика | Две локальные WOFF2-гарнитуры, Mulish с настоящим курсивом, Commissioner для рабочего текста; крупное плотно, мелкий капс разрежённо; повествовательный текст ≥16 px |
| Дудлы | Четыре нейтральных SVG: листик у фото, звёздочка у рецептуры, сердечко у ритуала, волна в финале. В карточке листик заменён на один дудл SKU |
| Формат SVG | 11 исходников скопированы без изменения байтов. CSS mask с `contain` и `currentColor` сохраняет пропорции и живую линию. Дудлы декоративные, вне кнопок и полей |
| Движение | Действующий Serega для заголовков; у дудлов мягкий отклик 400 мс, у фото 500 мс, без циклов. Reduced motion отключает эффекты |
| Продажа | Растение → диаметр нового горшка → полная цена бокса → демонстрация перехода на маркетплейс. На компьютере покупка на первом экране; на телефоне закреплена снизу |
| Смысл | Бокс на одну пересадку → комплектация → семь растений → зачем состав → ритуал → дневник на год → покупка |
| Голос Насти | Дословная разрешённая краткая цитата «Чем больше цифры — тем важнее земля.» с атрибуцией |
| Фотографии | Два реальных собранных бокса; остальные пять SKU показывают собственную раскладку. Чужой антуриум не подменяет их продукт. Сохранены макро, дневники, фото рук |

Тексты нового варианта остаются черновиком на просмотр Настей. Это не утверждение, что реализован весь августовский патч: формы, юридические сценарии и основной сайт в этой итерации не перерабатывались. Юридическое содержание и подробная лаборатория переиспользованы из предыдущей версии концептов.

## Внешние референсы

- [Обсуждение красивых сайтов на Reddit](https://www.reddit.com/r/web_design/comments/1wd7yvf/best_designed_websites_you_look_at_for_inspo/) → [Hôtel Weekend](https://www.hotel-weekend.com/): лично просмотрены первый экран, материальная фотография и тихая навигация.
- [Lurkshop](https://www.thelurkshop.com/): лично просмотрены характер типографики и выразительный кадр; его чёрно-оранжевая палитра не переносилась в бренд.
- [Work Louder](https://worklouder.cc/): изучено содержимое страницы, визуальная загрузка в автоматическом браузере не завершилась; источник не выдаётся за визуально проверенный.
- [Обсуждение типографики и Aesop](https://www.reddit.com/r/typography/comments/c27zig/): поисковый результат; сам Aesop закрыл автоматический браузер проверкой. Главные правила шрифта берутся из БЗ Насти с её разбором Haeckels/Frama.

Референсы — идеи композиции, не доказательство роста конверсии. Чужие фотографии в макет не переносились.
