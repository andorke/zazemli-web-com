# Архитектура

Фронтенд ЗАЗЕМЛИ — статический экспорт Next.js на nginx. Окончательный внешний вид переносится из зафиксированной передачи «Тёплая бумага». Покупка происходит на Ozon. Настройку и выпуск описывает [WARM-PAPER.md](deploy/WARM-PAPER.md).

| Часть | Ответственность |
| --- | --- |
| `src/app/` | Главная, четыре раздела и документы, семь индексируемых товаров, 404, метаданные. Сохранена отдельная инструкция перевалки. |
| `src/components/sections/paper/` | React-компоненты итоговой вёрстки, общий каталог, лаборатория, две формы, cookie. Обычные ссылки между страницами загружают каскад соответствующего документа. |
| `src/content/paper/` | Растения, фото, рецептуры, области раскладки, варианты покупки, тексты и версии согласия из передачи. |
| `public/warm-paper/` | Оригинальные WebP и локальные шрифты. Каскад каждой страницы перенесён из утверждённого HTML. |
| `src/lib/metrika.ts` | Счётчик только после согласия, остановка при отзыве, один pageview на переход, явные цели. В события передаются только допустимые технические значения. |
| `server/forms/` | Python и SQLite. Проверка тела и согласий, устойчивое сохранение, раздельные назначения Sendsay, повтор, разовые выпуски по растениям. |
| `deploy/` | Nginx: совместимость адресов, статическая 404, HTTPS и API. Unit systemd: локальный приёмник с приватным состоянием. |

Браузер отправляет JSON на тот же origin. `POST /api/waitlist/plant` сохраняет имя и возвращает `requestId`. `POST /api/waitlist/email` и `POST /api/diary/subscribe` принимают email, два непредзаполненных согласия и их версию. В ожидании обязательна связь с `requestId`. Публичный успешный результат зависит от сохранённой записи и принятия контакта правильным списком Sendsay. Контакты, согласия, результаты и повторы остаются за пределами статической сборки.

`/collectio`, старый якорь `#collectio`, `/snova/{plant}`, `/lab#rec-{plant}` и QR коротких страниц сохраняются. В nginx описаны HTTP-алиасы и передача query. Ссылки Ozon берутся из проверенных предложений, а объём горшка хранится отдельно от фасовки. Метрика считает клик Ozon, данные о покупке из него не выводятся.

Конфигурация кандидата использует `/var/www/zazemli-current`, отдельные release-каталоги и подготовленный возврат на предыдущую версию. База форм находится вне каталога релиза. Площадка `/rubinovoe-more/` обслуживается отдельно из `/var/www/zazemli-experiments/rubinovoe-more`.
