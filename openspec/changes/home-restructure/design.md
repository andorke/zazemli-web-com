# home-restructure — design

## Context

Главная собрана по `home.md` v2.1 (change `landing-redesign`, применён, не заархивирован): 11 блоков, включая манифест и колбы. PATCH-1 §2 переводит канон на v2.5. Прошлая итерация ошиблась именно на сверке версий канона (v2.3 против v2.5 — позиция «Что в боксе»), поэтому источник версии фиксируется явно.

## Goals / Non-Goals

**Goals:**
- Привести структуру, тексты и цены главной к home.md v2.5 / актуальному `landing.html`.
- Убрать дубли состава бокса (главная ↔ 7 карточек) в один контент-модуль.
- Закрыть FIX-14: grid внутри секций, симметрия полей на широких вьюпортах.

**Non-Goals:**
- Механика плитки N°08 (попап, согласия) — change `waitlist-form`; здесь только место в гриде и защита от протечки стилей (NEW-01).
- Смена шрифта и трекинг — change `font-mulish`.
- OG/JSON-LD, `next/image` — change `seo-meta`.

## Decisions

1. **Снос компонентов, не скрытие**: `manifesto.tsx`, `different-soil.tsx` и их контент/тесты удаляются; трио колб воссоздаётся на `/lab` по прототипу `lab.html` (не переносом кода — разметка в прототипе новая). CSS снятых блоков не переносится (FIX-78: в `landing.html` остался мёртвый CSS секции колб и `.split` манифеста — это не спека для Tailwind).
2. **Состав бокса — отдельный контент-модуль** (например, `src/content/box.ts`), импортируемый главной и `sku`-страницами. Альтернатива (дублировать в `home.ts` и `sku.ts` с drift-тестом) отклонена: патч прямо требует идентичности — единый источник дешевле теста на дрейф.
3. **Блок «Купить»**: плитки размеров — `div` с рамкой, без hover-аффордансов кнопки (ложную кликабельность аудит уже ловил). Данные объёмов/горшков — из `sku.ts`-размеров, чтобы при открытии Ozon плитки стали `<a>` на листинги одной правкой.
4. **Сверка текстов — по канону, с прогоном обоих вариантов пробела** (обычный и U+00A0): на неразрывном пробеле прошлая итерация насчитала 9 старых цен вместо 31 (PATCH-1 §6). Тест цен ищет оба варианта.
5. **Порядок и состав блоков финально сверяются с актуальным `landing.html`** (правило источников §0: канон → прототип): судьба атмосферного фото-баннера в v2.5 не проговорена в патче — при переносе следовать прототипу, не выдумывать.

## Risks / Trade-offs

- Крупная перестановка секций ломает существующие e2e/снапшоты главной — обновление тестов входит в задачи.
- Пересечение с `waitlist-form` в галерее: договорённость — здесь галерея меняется только по заголовку/ссылкам карточек; плитка N°08 остаётся в текущем виде до `waitlist-form`.
- Пока `font-mulish` не применён, визуальная сверка с прототипами будет расходиться по гарнитуре — сверять структуру/тексты, не пиксели.
