# font-mulish — design

## Context

Voice-роль закрывает Literata как «временный дублёр» (fonts.ts, комментарий DS-контракта v1.1.0): канонный Newsreader не имеет кириллицы. PATCH-1 §1 (решение Насты 30.07) назначает финальное семейство — Mulish. Типографика канона переехала в `typography.md` v3.0; `tokens.json` в vault остался v1.1.0 и по шрифту/трекингу отстаёт — источник для этой работы: PATCH-1 §1 + прототипы (`Айти/Сайт/prototypes/`).

## Goals / Non-Goals

**Goals:**
- Сменить voice-семейство на self-hosted Mulish без смены механики подключения (`next/font/local`).
- Ввести трекинг-шкалу как токены и применить к ролям.
- Вычистить Literata/Newsreader из кода, шрифтов и тестов.

**Non-Goals:**
- Схлопывание типо-шкалы до 9 токенов (FIX-15) — волна 2; кегли не трогаем.
- Смена ui-семейства (Commissioner остаётся как есть).
- Правка канона vault (tokens.json v1.2 — на стороне Насты; расхождение фиксируем в CONTEXT).

## Decisions

1. **Файлы шрифта: variable woff2 roman + italic, субсет cyrillic+latin.** Повторяем схему Literata: `mulish-var.woff2` (wght-диапазон обрезан до 300–600) + `mulish-var-italic.woff2` (300–400). Источник — Google Fonts (OFL), субсеттинг `pyftsubset` с сохранением оси wght. Альтернатива (статические 4 файла) отклонена: variable уже принят в DS и меньше суммарно.
2. **Fallback через опцию `fallback` в `localFont`** (`['Helvetica Neue', 'Arial', 'sans-serif']`) + `adjustFontFallback` по умолчанию. Georgia убирается: смена породы сериф→гротеск делает прежнее правило вредным (скачок метрик при swap).
3. **Трекинг — CSS-переменные `--tracking-*` в `globals.css`**, применение в классах/компонентах ролей. Не Tailwind-literal в компонентах: токен должен жить в одном месте (правило «хардкод запрещён» распространяется на letter-spacing заголовков).
4. **Веса заголовков — 300–400 по прототипам**, канон typography.md v3.0 (600) игнорируем осознанно: расхождение задокументировано в PATCH-1 §1 как известное, источник до правки канона — прототип. Отдельного токена h2 нет — h2 набирается кеглем h1 (тоже осознанно, по прототипу).
5. **Preload оставляем как у Literata** (оба voice-файла): прежний замер LH показал, что поздний swap бьёт по FCP сильнее preload; после замены семейства перепроверить размер файлов (Mulish-субсет ожидаемо легче серифа).

## Risks / Trade-offs

- **Оба семейства — гротески**: различие заголовок/тело держат только вес и трекинг. Риск нечитаемого стыка h2 → body; лечится усилением трекинга заголовка (не сменой шрифта) — проверка в приёмке.
- **Метрики строк поплывут** (сериф→гротеск): возможны переносы/высоты не как раньше; прототипы — эталон, сверять по ним.
- Пока vault-канон (tokens.json) не обновлён, двоевластие источников: закрывается записью в CONTEXT + флагом Насте.
