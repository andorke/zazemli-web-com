# guide-v4 — design

## Context

`/guide` собран по `guide.md` v3.0: 5 линейных стадий + HowTo (коммиты `559ad65`, `cc20651`). Канон v4.0 (PATCH-1 §4, полный handoff — `Zazemli-work/tasks/2026-07-30_HANDOFF_guide-v4-to-build.md`) делит гайд на вход и два маршрута; прототипы `guide-perevalka.html` / `guide-polnaya-zamena.html` приехали в vault 01.08.

## Goals / Non-Goals

**Goals:**
- Три страницы по прототипам, contentful-структура из `guide.ts`.
- SEO-контракт (noindex/canonical) — защита от каннибализации дословно совпадающих шагов.
- Общие компоненты для посимвольно идентичных кусков.

**Non-Goals:**
- Иллюстрации (сняты Настей 30.07; спека будущего — `2026-07-30_guide-illustration-spec.md`).
- Своя статья про гниль корней (пока внешняя ссылка, сменится одной правкой).
- Блоки «Готово, когда» (FIX-62 отменён — не «восстанавливать»).

## Decisions

1. **Роутинг — вложенные статические роуты** `src/app/guide/{page,perevalka/page,polnaya-zamena/page}.tsx`; static export даёт HTML каждой. Динамический `[route]` отклонён: маршрутов ровно два, страницы различаются структурой (у полной замены есть «01 Продолжение»).
2. **Контент — один модуль `guide.ts`** с общими шагами как разделяемыми объектами: «Дренаж», «Дневник», «Сохрани остаток» определяются один раз и включаются в обе ветки по ссылке. Идентичность гарантируется структурой данных, а не тестом на дрейф.
3. **HowTo — по одному на ветку, вход без HowTo.** Патч оставляет выбор нам (§4.4); альтернатива «один HowTo на входе с общими шагами» отклонена: вход не содержит шагов 02–04, а HowTo, описывающий контент чужой страницы, хуже отсутствия разметки. На ветках линейность восстановлена — HowTo честный. Ветки noindex — допустимо: разметка нужна не для сниппета веток, а для целостности данных; вход остаётся индексируемым без HowTo.
4. **`generateMetadata` на всех трёх страницах**: canonical входа проставляем сами (в прототипе его нет — патч §4.1 прямо требует не забыть); noindex/canonical веток — из прототипов, не потерять при переносе.
5. **`.reveal` остаётся, ничего сверх** (FIX-64): существующая анимация появления — потолок.

## Risks / Trade-offs

- Существующие e2e гайда и тест HowTo ломаются структурно — переписываются под три страницы (это ожидаемая стоимость смены канона).
- Внешняя ссылка на epicgardening — временная зависимость от чужого контента; помечена в контенте комментарием для будущей замены.
- QR/печатные материалы, ведущие на `/guide`, не страдают: вход остаётся тем же URL.
