# lab-page — delta (home-restructure)

## ADDED Requirements

### Requirement: Трио колб на входе лаборатории

Вход `/lab` SHALL открываться блоком «Разным растениям — разная земля» с трио колб (переезд с главной, PATCH-1 §2 / FIX-78) по разметке актуального прототипа `lab.html`. На главной этого блока MUST NOT быть.

#### Scenario: Колбы на входе /lab
- **WHEN** отрендерена `/lab`
- **THEN** блок «Разным растениям — разная земля» с тремя колбами присутствует в верхней части страницы по прототипу

#### Scenario: На главной колб нет
- **WHEN** отрендерена `/`
- **THEN** заголовка «Разным растениям — разная земля» и трио колб на странице нет
