# home-restructure

## Why

Канон главной сменился: `home.md` v2.5 (PATCH-1 §2, решения Насты 30.07). Прежняя структура (11 блоков по v2.1, реализована в `landing-redesign`) устарела: «Что в боксе» поднят на вторую позицию (FIX-13 — именно на этой сверке ошиблась прошлая итерация, сверявшаяся с v2.3), манифест и колбы сняты с главной, блок «Купить» переработан до «только размеры» (NEW-03), цены выросли (FIX-02).

## What Changes

- **Порядок блоков v2.5 (не переставлять):** Hero → «Что в боксе» → галерея 7 SKU → «Три шага» → «Что эта земля даёт» → «О нас» → тизеры → «Купить» → футер.
- **Снос:** секция-манифест со сплитом «Для растения / Для тебя» (лид «Пересадка выглядит как дело на вечер. По сути — пауза» переезжает лидом в «Три шага»); блок колб «Разным растениям — разная земля» (трио переезжает на вход `/lab`). Мёртвый CSS снятых блоков в Tailwind не переносить (FIX-78).
- **«Что в боксе»:** состав — грунт (+ссылка в лабораторию), дренаж, «Забота о корнях и твоих руках» с 4 подпунктами (перчатки / 2 палочки для корней / баночка угольной пудры / корневин), дневник, листовка; **идентичен на главной и 7 карточках** — единый контент-источник (FIX-05/36/49/52/53/70).
- **«Купить» (NEW-03):** только размеры — три некликабельные плитки в рамках (объём крупно + «горшок 12–13 / 15–16 / 18–20 см»), строка «Пересаживают раз в год, весной», кнопка Ozon, risk-reversal «…team@zazemli.com» (FIX-35). Сняты тейк Т3, кофе-якорь, финал-мысль.
- **Т3** «Бокс заканчивается в день пересадки. Дневник — нет» → закрывающая строка шага 03 «Ведёшь дневник» (NEW-04), отделена линейкой, moss-ink.
- Цены **1 990 / 2 290 / 2 690 ₽** (FIX-02); hero-sub и шаг 01 без «природной почвы» (FIX-04); core formula «Земля и забота — всё, что нужно» закрывает «Что эта земля даёт» (FIX-72); «О нас» — редакция v2.2 (FIX-28); «семь рецеп**тур**» (FIX-27); фото-плейсхолдеры — нейтральная заливка `--chalk` без квадратных скобок (FIX-03).
- **Сетка (FIX-14):** воспроизвести в Tailwind grid-классы прототипа (`.wrap` c max-width/auto-margin, `.split{1fr 1fr}`, `.boxsec{.9fr 1.1fr}`, `.gives{1fr 1fr}`, `.teasers{repeat(3,1fr)}`, брейкпоинт 860) — сейчас взят контейнер, но не grid внутри секций.
