## Why

QR-коды партии 0 уже напечатаны на пачках грунта и ведут на четыре страницы: `/guide`, `/lab`, `/collectio`, `/diary-signup`. Сканирующий покупатель — самый горячий посетитель сайта (пачка буквально в руках), но сейчас он попадает на полностью статичные страницы: момент перехода «физический продукт → цифровой опыт» никак не обыгран. Решение владельца (интервью 2026-08-01): сделать заметную wow-встречу в тематике каждой страницы, флагман — `/guide`, плюс тематический интерактивный слой (курсор/тап).

## What Changes

- **Entrance-хореография первого экрана** на четырёх QR-входах: каскадное появление hero-элементов (staggered reveal), show-once за сессию. Вход `/collectio` встречается на главной при заходе на `/#collectio` — существующий редирект сохраняется. Флагман по выразительности — `/guide`.
- **Тематический интерактивный слой**: cursor-follower на устройствах с мышью (`pointer: fine`) с реакцией на клик; на тач-устройствах — эффект в точке тапа. Тематика — грунт/растения (финальный образ выбирается на этапе design).
- **Точечные исключения из принципа «MVP без анимации»** (фиксируются дельтой спеки `design-system`, остальные запреты сохраняются): разрешить sequential reveal для entrance-хореографии; утвердить entrance-тайминги; допустить vanilla rAF-цикл для интерактивного слоя. Без новых зависимостей — только CSS + vanilla JS.
- **Motion-фундамент**: duration-токены из `tokens.json.motion` (`fast 150 / base 200 / medium 300 / slow 400 / page 600`) портируются в `globals.css` рядом с уже существующими easing-токенами.
- **Конвенция QR будущих партий**: параметр источника (`?src=qr`, опционально `&sku=…`) включает лёгкий контекстный слой встречи. Партия 0 напечатана с чистыми путями — встреча показывается всем посетителям (show-once), деградации для неё нет.
- **prefers-reduced-motion**: entrance и курсор-слой полностью отключаются (глобальный механизм в `globals.css` уже есть, новые слои обязаны под него попадать).

## Capabilities

### New Capabilities
- `welcome-choreography`: entrance-встреча QR-входов — каскад первого экрана, show-once логика, обработка `?src=qr` для будущих партий, полное отключение при reduced-motion, perf-границы (LCP-элемент не скрывается до JS).
- `cursor-companion`: тематический интерактивный слой — cursor-follower (десктоп), реакция на клик, tap-эффект (тач), гейтинг по типу устройства, недопустимость перехвата кликов/скролла.

### Modified Capabilities
- `design-system`: motion-раздел — duration-токены становятся обязательной частью темы; точечные исключения из «MVP без анимации» (entrance sequential reveal, vanilla rAF для интерактивного слоя) при сохранении всех остальных ограничений (composited-свойства opacity/transform, запрет теней/радиусов, запрет JS-библиотек анимации).

## Impact

- **Код**: hero-секции `src/components/sections/{guide,lab,home,diary}/`; новая директория motion-примитивов (Reveal-оркестратор, cursor-слой); `src/app/globals.css` (duration-токены, entrance-keyframes); `src/app/layout.tsx` (подключение курсор-слоя, анти-FOUC show-once скрипт); секция `SkuGallery` на главной (встреча `#collectio`-захода).
- **Спеки**: новые `welcome-choreography`, `cursor-companion`; дельта `design-system`. Страничные спеки (`guide-page`, `lab-page`, `homepage`, `diary-signup`) не меняются — их контентные требования не затрагиваются.
- **Документация**: принцип «MVP без анимации» в `REQUIREMENTS.md` получает оговорку об entrance-исключениях после архивации change.
- **Тесты/качество**: `npm run build` и `npm run ds-lint` зелёные; unit на show-once/гейтинг; e2e-прогон четырёх входов (desktop 1440 + mobile 360); `prefers-reduced-motion` проверяется в e2e.
- **Perf**: entrance не скрывает LCP-элемент (первый экран читаем без JS); курсор-слой загружается лениво и только на `pointer: fine`; мобильный LCP (известное слабое место ~8.8s) не ухудшается.
- **Вне скоупа**: аналитика сканов (capability `analytics-consent`), печать новых QR, SSR.
